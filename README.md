# Terminal Runner

A 3‑lane dodging game made in Python.  
Cars come at you, coins give you points, and you switch lanes to survive.

## Controls
- A → left lane  
- C → middle lane  
- B → right lane  

## How to Play
Run the game and avoid the cars (🚗).  
Collect coins (💰) to increase your score.

## Running from Source
1. Install Python.
2. Install the keyboard library:
   pip install keyboard
3. Run:
   python game.py

## Windows EXE
If you're on Windows, you can run the standalone `game.exe` inside the `dist` folder.
